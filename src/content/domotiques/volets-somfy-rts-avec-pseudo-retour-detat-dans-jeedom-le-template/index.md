# Volets Somfy RTS avec pseudo retour d’état dans Jeedom le Template

> ~Bonjour, en tant que contributeurs vous avez accès à des bonus et pour vous évitez de créer le scénario je vous partage le Template à importer~

[Télécharger](<../../../../public/partages/Scenarios_importer/Volets Somfy RTS.rar>)

**Rappel :** 

- Les commandes du plugin RFXCom sont sous la forme **#\[Salon\]\[Volet\]\[COMMANDE\]#** et les commandes du virtuel sont sous la forme **#\[Salon\]\[Volets Salon\]\[COMMANDE\]#**.

**Pour importer le Template :** 

- Allez dans **Outils**.
- Puis **Scénarios**.
- Cliquer sur **Ajouter**.
- Donnez un **nom à votre scénario.**
- Cocher **Actif**  **Visible** .
- Cliquer sur Template en haut à droite.
- Sélectionner le Template à gauche.
- Rechercher vos commandes.
- Modifier les variables si besoin.
- Cliquer sur Appliquer.
- Cliquer sur D’accord lorsque vous aurez le message « Etes-vous sûr de vouloir appliquer le template ? Cela écrasera le scénario si il y en a un ».
- Fermer la fenêtre « Template de scénario ».
- sortir du scenario.
- Revenir dans le scenario.
